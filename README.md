## How to Run the Scripts

1. Open the Ubuntu Terminal.
2. Navigate to the project directory.
3. Give execute permission to the script:

   ```bash
   chmod +x filename.sh
   ```

4. Run the script:

   ```bash
   ./filename.sh
   ```

Replace `filename.sh` with the required script name.
